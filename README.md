# 句读：GitHub Pages 发布版

这是纯浏览器网站，可直接发布到 GitHub Pages。访问者不需要 Python、终端或 API 密钥。Excel 在访问者的浏览器中读取，文章和解析不上传服务器；阅读数据保存在该浏览器中。

## 上传和开启 GitHub Pages

1. 在 GitHub 创建一个仓库，例如 `sentence-reader`。使用免费个人账户时，选择 Public。
2. 解压发布包，上传里面的文件和文件夹到仓库根目录。不要只上传 ZIP，也不要多套一层文件夹。
3. 根目录应该直接看到 `index.html`、`app.js`、`import-browser.js`、`styles.css`、`assets/` 和 `vendor/`。同时保留 `.nojekyll`；如果 Finder 隐藏它，可用 Command+Shift+. 显示隐藏文件，或在 GitHub 创建一个名为 `.nojekyll` 的空文件。
4. 打开仓库 **Settings → Pages**，选择 **Deploy from a branch**，分支为 **main**，文件夹为 **/(root)**，点击 **Save**。
5. 等待部署成功后，Pages 会显示网站地址，通常是 `https://你的用户名.github.io/sentence-reader/`。
6. 打开网站，先点击“体验示例文章”，或导入 `assets/示例文章.xlsx` 验证。

无需构建命令、Python 服务或环境变量。不要把旧版的 server.py 或启动文件上传到此发布目录。这里提供的是发布文件，尚未替你创建仓库或发布网站。

官方说明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 使用

- Excel：第一列是句子，第二列是完整翻译与语法解析；建议表头为“句子”“解析”。一句一行，空行分段，一张工作表一篇文章。
- 手机端长按句子约 0.55 秒弹出解析；移动手指、滑动页面或多指操作会取消长按。弹窗内文字仍可选中复制。
- 电脑端默认按住空格并左键点击句子。设置中可自定义键盘组合，左键固定。Esc 用于关闭弹窗；也可以 Tab 聚焦句子后按 Enter。
- 点击范围依据句子实际换行后的文字区域计算；普通点击或拖动仍可选择文字。
- 网站内提供可复制、下载的 AI 提示词和完整的示例 Excel。它显示已导入的翻译和解析，不自动调用 AI 生成解析。
- 支持未加密的 `.xlsx` 和 `.csv`，包括 Numbers 导出的 `.xlsx`；旧 `.xls` 需先另存为 `.xlsx`。不接受合并单元格或公式，请先转为普通单元格和文本值。
- 可一次选择或拖入多个文件；同批次按文件选择顺序、各工作表顺序导入，新批次显示在列表最前面。刷新后保留该顺序。每个文件上限 10 MB，解压后上限 40 MB；每张表最多 5,000 句，每次最多 50 张非空工作表。
- 缺少解析的句子会保留并提示。重复句子逐行关联，不去重。
- 可在导入 Excel 后选择“匹配原文 TXT”，加载 UTF-8 原文并匹配对应句子；未匹配内容会标示，不会借用其他句子的解析。
- 文章与设置保存在当前浏览器、当前网站路径下。清理网站数据可能丢失记录；更换设备、浏览器、域名或仓库路径后需要重新导入，请保留原始 Excel。
- 不要将你自己的学习文章放进公开仓库，除非你希望它成为公开文件。用户在网页中导入的文件不会自动进入仓库。

## 更新网站

将修改后的对应网站文件上传到同一仓库并提交即可，GitHub Pages 会重新发布。不要删除需要保留的 assets 或 vendor 文件夹。更新后如果看到旧页面，可刷新浏览器。

## 文件说明

- `index.html`、`styles.css`、`app.js`：页面、样式和阅读交互。
- `import-browser.js`：浏览器端 Excel、CSV 解析。
- `vendor/jszip.min.js`：随网站一起提供的 ZIP 解压库，不依赖外部 CDN。
- `vendor/JSZip-LICENSE.md`：第三方许可，本项目按 MIT 许可使用 JSZip。
- `assets/示例文章.xlsx`：博物馆故事的 15 句完整翻译与解析。
- `assets/AI提示词.md`：让 AI 生成两列解析 Excel 的完整提示词。
- `assets/sample.json`：内置示例。
- `.nojekyll`：让 GitHub Pages 直接提供静态文件。

建议使用近期版本的 Chrome、Edge、Safari 或 Firefox。直接双击本地 index.html 不是本包的部署方式，请通过 GitHub Pages 网址访问。

## 批量阅读

每篇文章独占一张工作表，表名为标题，按希望阅读的顺序排列。空行只分段，不划分文章。篇末可点击上一篇／下一篇连续阅读，跳转后自动回到文章标题位置；首页和末篇的边界按钮会禁用。不同文章即使同名、同句，也各自保留解析。

## 可自定义快捷键与交互练习

在“阅读与快捷键设置”中，可以分别录制查询、上一句、下一句、上一篇、下一篇的按键组合。解析打开时启用上下句快捷键，关闭时启用篇章快捷键；输入框与设置窗口中的按键不被导航截获。默认上下方向键切句、左右方向键换篇，Esc 关闭解析。关闭解析后上下键正常滚动。

同一模式的两个导航不能设置为相同组合；查询键与导航键不能相互包含，以避免触发歧义。设置会保存在当前浏览器，支持恢复默认。录制中按 Esc 只取消此次录制。

点击“体验示例文章”可进行六步练习：打开解析、下一句、上一句、关闭解析、下一篇、上一篇。引导显示当前自定义键位，按真实操作逐步推进；按键提示与目标句带有轻微动效，并尊重系统的减少动态效果偏好。练习可随时跳过或重启。两篇示例均为语言学习用虚构故事。

## 阅读配色

右上角“外观”提供跟随系统、纸白、暖纸、深夜；文字提供标准、柔和、高对比。点击即生效并保存在当前浏览器。正文、侧栏、解析弹窗与设置均适配深色，也支持手机宽度。外观选择不影响已保存文章与快捷键。

采用分层的深色表面和可读的文字对比，而非把页面简单反色。12 种正文背景／文字组合的对比度已检查；配色参考 Apple 深色模式指导，文字对比参考 WCAG 普通文本 4.5:1 标准。这不代表对网站进行了完整 WCAG 合规审计。

参考：https://developer.apple.com/design/human-interface-guidelines/dark-mode
参考：https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum

默认外观为“专注白”：文章区白底黑字，中性浅灰侧栏，蓝色用于主要操作、选中状态与链接。参考 IBM Carbon 的中性灰分层和蓝色交互色职责，不复制其完整布局。原“清朗蓝”选项已更新为专注白；深色选项仍保留。跟随系统模式在浅色时使用专注白，深色时使用深夜。

## 轻量复习
在句子解析中点击「加入复习」，可填写回忆重点（词组、用法或整句意思）。左侧「轻量复习」显示到期卡数，每轮最多 5 张；先回忆再展开原解析，自评后安排下次时间：忘了 10 分钟，模糊 1 天，记住了逐步间隔 1 / 3 / 7 / 14 / 30 / 60 天。属于简化复习安排，不判断答案正误，也不调用 AI。

复习卡包含原句和解析的独立副本，删除文章不会删除卡片；可在复习时移出卡片。卡片和进度仅保存在当前浏览器、当前网站路径下，不跨设备同步。复习窗口底部支持 JSON 备份导出和导入（按卡片 ID 合并，保留已有进度）。迁移域名或清除浏览器数据前，请先导出备份。关闭网页期间不会推送提醒，再次打开后显示到期数。

## 手机菜单、滑动与粘贴导入
手机宽度下，顶部只保留一行菜单栏。点击「菜单」展开文章列表、导入、复习、设置及外观等功能，选择功能后自动收起。

在正文区域左滑切换下一篇、右滑上一篇；打开句子解析后，在解析内容区域左滑下一句、右滑上一句。上下滑动保持滚动；小幅、明显斜向、多指手势及按钮操作不触发翻篇，首尾不会循环。系统从屏幕边缘开始的返回手势可能由浏览器优先处理，请在内容区域内滑动。

「粘贴解析文本」支持 AI 输出的 JSON（可包含完整 Markdown JSON 代码块）。复制入口内专用提示词或 assets/文本解析AI提示词.md，给 AI 附上原文；将完整输出粘贴后点击「导入并阅读」。格式为 {"articles":[{"title":"标题","entries":[{"sentence":"原句","paragraph":1,"analysis":"解析"}]}]}，每张卡必须有完整原句、解析及段落序号；每批最多 50 篇、每篇最多 5000 句。网页先验证整批格式，再导入；不调用 AI，无法自动验证 AI 有无遗漏原文，阅读前请核对内容。
